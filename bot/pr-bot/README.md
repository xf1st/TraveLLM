# TraveLM PR-бот — Инструкция по настройке

## Что делает бот

Принимает от авторизованных пользователей краткое описание (+ опционально фото),
генерирует нормальный Telegram-пост через DeepSeek и публикует его в группе.

---

## Шаг 1 — Создай бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Придумай имя, например: `TraveLM Updates`
4. Придумай username, например: `travellm_pr_bot`
5. BotFather выдаст токен вида `123456789:AABBcc...`

---

## Шаг 2 — Добавь токен в .env

Открой `.env` в корне проекта и добавь строку:

```
TELEGRAM_BOT_TOKEN_PR=123456789:AABBcc...твой_токен_здесь
```

---

## Шаг 3 — Добавь бота в группу

1. Открой свою Telegram-группу
2. Нажми на название группы → Добавить участника
3. Найди своего бота по username и добавь
4. **Важно**: сделай бота администратором группы (иначе он не сможет отправлять сообщения в некоторых группах)

Чтобы сделать администратором:
Настройки группы → Администраторы → Добавить администратора → выбери бота

---

## Шаг 4 — Установи зависимости и запусти

```bash
cd bot/pr-bot
npm install
npm start
```

Для разработки с авто-перезапуском:
```bash
npm run dev
```

---

## Шаг 5 — Запуск на сервере (продакшн)

На Coolify/VPS рядом с основным приложением можно запустить через PM2:

```bash
npm install -g pm2
cd bot/pr-bot
npm install
pm2 start index.js --name travellm-pr-bot
pm2 save
pm2 startup
```

Или через Docker — добавь в `docker-compose.yml` отдельный сервис.

## Использование

### Текстовый пост
```
/post Запустили 3D-режим карты — теперь маршрут можно смотреть как глобус
```

### Пост с одним фото
Отправь фото с подписью:
```
/post Обновили AI-гида: теперь он знает актуальные цены
```

### Пост с альбомом (несколько фото)
Отправь несколько фото как альбом (медиагруппу), в подписи первого:
```
/post Новый интерфейс маршрута — скриншоты внутри
```

### Справка
```
/help
```

## Как бот генерирует текст

- Использует DeepSeek (`deepseek-chat`)
- В системном промпте есть описание TraveLM — бот знает о чём пишет
- Без markdown форматирования (`**жирный**`, `__курсив__`) — только чистый текст и эмодзи
- Длина поста 80–180 слов
- Заканчивает вопросом к аудитории или призывом к действию

Чтобы изменить стиль постов — редактируй `systemPrompt` в `index.js` в функции `generatePost()`.
