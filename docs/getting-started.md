# 🏁 Начало работы

Начать пользоваться TraveLLM очень просто. Вам не нужно устанавливать приложений — сервис работает прямо в браузере как прогрессивное веб-приложение (PWA).

## 1. Регистрация и Вход

Чтобы сохранять свои маршруты и получать доступ к ним с любого устройства, необходимо авторизоваться.

Мы поддерживаем современные и безопасные способы входа:

- 🔐 **Google** — быстрый вход для большинства пользователей.
- 🐙 **GitHub** — для разработчиков и технарей.
- 📧 **Email** — классический вход по почте с подтверждением (Magic Link).

> **Важно**: Без регистрации доступен только режим просмотра демо-маршрутов. Для генерации собственных путешествий требуется аккаунт.

## 2. Навигация по сервису

После входа вы увидите **Главный экран**, который адаптируется под вас:

- **Верхняя панель**: Быстрый доступ к профилю и переключатель темы (Светлая/Темная).
- **Секция "Активные поездки"**: Если у вас есть запланированное путешествие, оно будет отображаться первым с таймером обратного отсчета.
- **История**: Список всех ваших сгенерированных ранее маршрутов.

## 3. Создание первого маршрута

Процесс создания максимально упрощен:

1.  Нажмите кнопку **"Создать маршрут"** или **"Новое приключение"**.
2.  Вы перейдете на экран планирования (подробнее в разделе [Планирование](features/planning.md)).
3.  Заполните форму предпочтений и нажмите "Поехали!".
