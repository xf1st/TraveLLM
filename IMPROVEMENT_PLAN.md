## Задача 2: Гибкая генерация маршрутов + персонализация

### Концепция:
Маршрут должен соответствовать **запросу пользователя** и быть **персонализирован под его профиль**:
- Если пользователь хочет несколько стран → генерируем мультистрановой маршрут
- Если пользователь хочет одну страну → генерируем маршрут по городам этой страны
- Если пользователь хочет один город → генерируем детальный маршрут по районам/достопримечательностям

### Проблемы:
- `countryCount="more"` → `parseInt("more") = NaN` → defaults to 2
- `"events"` отсутствует в `STYLE_TO_TAGS` → не влияет на персонализацию
- AI prompt не учитывает гибкость формата маршрута

### Решение:

**1. Исправить обработку countryCount:**
```javascript
// В /api/deepseek/route.ts
const countryNum = countryCount === "more" ? 4 : parseInt(countryCount) || 1
```

**2. Добавить "events" в STYLE_TO_TAGS:**
```javascript
// В /lib/personalization.ts
"events": ["фестивали", "концерты", "карнавалы", "спортивные события", "выставки"]
```

**3. Обновить prompt для гибкой генерации:**
```
ВАЖНО: Создай маршрут точно по запросу пользователя:
- Если указано несколько стран (${countryNum}) → включи ровно столько стран
- Если указана одна страна → создай маршрут по разным городам этой страны
- Если указан один город → создай детальный маршрут по этому городу

Персонализация под профиль пользователя:
- Учитывай интересы: ${userInterests}
- Учитывай стиль путешествия: ${travelStyle}
- Учитывай бюджет и ограничения
```

**4. Валидация результата** - проверить соответствие запросу пользователя

### Файлы для изменения:
- `lib/personalization.ts` - добавить events в STYLE_TO_TAGS
- `app/api/deepseek/route.ts` - исправить countryCount, обновить prompt
- `app/plan/page.tsx` - валидация на клиенте

## Верификация

После каждого изменения:

1. `npm run build` - проверить что билд проходит
2. `npm run dev` - локальное тестирование
3. Проверить в браузере:
   - Desktop: Chrome, Firefox
   - Mobile: Chrome DevTools эмуляция

### Тестовые сценарии:
- **Гибкий маршрут**: Проверить генерацию для разных запросов:
  - Несколько стран → проверить что все страны в маршруте
  - Одна страна → проверить маршрут по городам
  - Один город → проверить детальный маршрут
- **Персонализация**: Проверить что маршрут учитывает профиль пользователя
- **Ивенты**: Выбрать "ивенты" → проверить что есть фестивали/концерты
- **Карта в маршруте**: Открыть маршрут → проверить карту внизу
- **Логистика**: Проверить время отправления между городами
- **Мобильный**: Проверить на 375px width
